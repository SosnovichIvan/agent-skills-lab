# Оформление навыков

Создавай каждый навык как самостоятельную папку в `skills/`. Единственная
обязательная точка входа — `SKILL.md`.

## Структура

Используй имя папки, совпадающее с именем навыка: строчные латинские буквы,
цифры и дефисы. Выбирай короткое действие или предметную область, например
`skill-authoring`.

```text
skills/<skill-name>/
├── SKILL.md
├── agents/             # только если нужны UI-метаданные
│   └── openai.yaml
├── prompts/            # только для готовых пользовательских/runtime-промптов
├── references/         # только для объёмных или контекстных материалов
├── scripts/            # только для повторяемой детерминированной логики
└── assets/             # только для файлов, используемых в результате
```

Не создавай пустые каталоги «на будущее». Добавляй `references/`, когда
детальная инструкция, схема или политика нужна лишь в отдельном сценарии;
из `SKILL.md` должна быть понятная ссылка и условие, когда её читать.
Готовые для копирования или внедрения промпты храни только в `prompts/`, а
исполняемый код — только в `scripts/`; не смешивай эти назначения.

## SKILL.md

Начинай файл с YAML frontmatter с полями `name` и `description`.

- `name` совпадает с именем папки.
- `description` кратко объясняет результат, условия применения и при
  необходимости границу с похожими задачами.
- Основной текст содержит только решения, ограничения и порядок действий,
  которые действительно меняют поведение агента.
- Не дублируй общие системные инструкции, учебники и очевидные действия.
- Для условных, подробных или редких сценариев используй прогрессивное
  раскрытие: короткое правило в `SKILL.md`, подробности — в `references/`.

## Добавление или обновление

1. Проверь, нет ли уже навыка с тем же назначением; расширяй существующий,
   если это сохраняет одну понятную точку входа.
2. Создай или обнови нужные файлы в папке навыка.
3. Добавь или обнови строку в `skills/README.md`: идентификатор навыка,
   относительная ссылка на `SKILL.md`, название правила и практическое
   назначение.
4. Проверь структуру командой
   `quick_validate.py <путь-к-папке-навыка>` из инструментария
   `skill-creator`.

Сохраняй автоматическое обнаружение навыка по умолчанию. Отключай его в
`agents/openai.yaml` только по явному требованию пользователя.
