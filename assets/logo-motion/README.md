# Три анимации логотипов

Открой index.html в современном браузере. Файл работает локально без сети и сборки.

- AI: диагональные части и вертикаль собираются с небольшим смещением по времени.
- Code: скобки расходятся из центра, слеш мягко встаёт на место.
- Layers: три модуля сходятся по разным траекториям.

Цикл 7.8 с, с длительной паузой на собранном знаке. Есть общая пауза,
повтор, скорость и смена фона. prefers-reduced-motion отключает движение.

*-animated.svg — автономные анимированные SVG, *-static.svg — статические версии.
Для управления из страницы вставляй SVG inline; для темы задавай --logo-ink.
В img внешний SVG не наследует цвет родительского элемента.

Геометрия вручную реконструирована по PNG-концептам, не является точной автотрассировкой.
Анимация выполнена SVG/CSS, без библиотек и внешних ресурсов.
