# Проверка icon-system

Три оригинальные векторные иконки: bench-press.svg, deadlift.svg, clusters.svg.

Сетка 96×96, stroke 3.5, round caps/joins. Основные размеры 48–96 px; 24–32 px требуют текстовой подписи. currentColor наследуется при inline SVG; внешний img не наследует цвет родителя. Для внешнего img нужно задать цвет внутри SVG или использовать mask.

index.html — контактный лист с реальными размерами 24/32/48/64 и переключением темы/монохрома.

Кластеры трактуются как взаимосвязанные группы узлов. Спортивные значки — обозначения упражнений, не инструкции по технике.
